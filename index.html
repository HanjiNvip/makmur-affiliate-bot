Makmur Affiliate Bot

Automation for TikTok Shop affiliate creators.

What it does

Makmur Affiliate Bot helps creators publish original product review videos to their own TikTok account through TikTok's official Content Posting API — and only after the creator authorizes the app themselves via TikTok's OAuth authorization page (scope: video.publish). No reposting, no stolen footage, no automated login.

How it works

  1. The bot researches TikTok Shop affiliate products and scores them.
  2. It generates original video concepts and runs them through quality checks.
  3. Only with the creator's explicit authorization, finished videos are uploaded via the official Content Posting API (Direct Post).
